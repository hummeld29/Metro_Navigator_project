# Linked_List
The linked list class creates a singly linked list. 
This list uses nodes to trach things like the size, head, or tail.
Whith this list you can add, remove, find and reverse stops.
# Hash_tabble
The hash tabble class creates a hash tabbke that stores string keys.
The hash tabble uses nodes to track objects.
# BST
The bst class creates a binary search tree that is built on tree nodes.
The bst has no list so instead of a list it reached nodes through root.
# Min_heap
The Min heap class creates a FIFO queue.
This min heap is built on a list that uses tuples to stire data.
# Graph
This class creates a graph that is built on top of the hash table.
The data is stired as edges in a list.
# Stack
The stack class creates a stack that is LIFO.
The stack is built on a linked list and can uses a stack for is balanced.
# Queue
The queue class creates a FIFO list built on the linked list.
the queue also has a function named hot potato and board passengers used to fill seats in arival order for its use in the station.

The hash set class creates a hash set that stores strings.
This hash set is built in the hash table and has the ability to add,ingersect , remove,contains, unioson, diffrece, and a little more.
